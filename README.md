# Addis Café

A static Ethiopian café menu built with React and Vite.

## Technologies

- React
- Vite
- JSX

## Features

- Reusable components
- Props
- JSX expressions
- map()
- React keys
- CSS styling
- Completed Challenges: Added location, 8 items, Footer component, emojis, and dynamic category styling.

## How to Run

1. `npm install`
2. `npm run dev`# addis-cafe
